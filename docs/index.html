Häufig gestellte Fragen (FAQ)

Antworten auf die wichtigsten Fragen rund um MC 3ver.

Funktioniert die Mod mit Forge oder NeoForge?

MC 3ver ist nativ für den Fabric Mod Loader gebaut. Mit Kompatibilitätslayern wie Sinytra Connector kann sie in bestimmten Setups laufen, empfohlen wird jedoch die Verwendung von Fabric.

Darf ich MC 3ver in meinem Modpack verwenden?

Ja! MC 3ver steht unter der MIT Lizenz und kann frei in öffentlichen oder privaten Modpacks auf Modrinth, CurseForge und GitHub eingebunden werden.

Wie kompiliere ich die Mod aus dem Quellcode selbst?

Klone das Repository und führe im Terminal einfach ./gradlew build (bzw. .\gradlew.bat build auf Windows) aus. Das fertige JAR findest du anschließend im Verzeichnis build/libs/.
